## 🔹 [BUS-IQ Transit Dashboard](https://github.com/DhruvilThummar/BUS-IQ)  
Ever wondered where your bus is? This real-time transit dashboard has all the answers!  

BUSIQ is a smart web-based tool for live bus tracking and fleet management. It shows real-time locations, performance stats, and alerts you about delays or bunching. Plus, it uses AI to give you optimization tips - making public transport smarter and faster!

**Cool features:**
- Live bus tracking on an interactive map
- Performance analytics and fleet management
- AI-powered route optimization suggestions
- Clean, responsive UI that works on any device

## 🔹 [Tourism Management System](https://github.com/DhruvilThummar/Tourism_Management_System)

This Java-based system makes travel planning a breeze - it handles **tour bookings, hotels, transportation, and complete itineraries** all in one place.  

**What makes it cool:**
- Secure role-based login (customers and admins get their own dashboards)
- Full CRUD operations for managing everything
- Built with **Java, MySQL, JDBC** and some solid data structures
